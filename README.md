# Lab-Exercise-6
AIM
To design and evaluate a Library Room Booking System that simplifies the process of reserving study rooms for students and faculty, focusing on usability, accessibility, and efficiency through user‑centered design principles.

ALGORITHM
Select the UX problem: difficulty in booking library study rooms.

Identify target users and their goals.

Observe existing booking systems and user interactions.

Collect user feedback through interviews and surveys.

Identify major pain points and usability issues.

Define a clear problem statement.

Create user personas representing different user types.

Map user journeys for booking and managing reservations.

Generate UX solutions and low‑fidelity prototypes.

Conduct usability testing with real users.

Record completion time, errors, and satisfaction levels.

Analyze feedback and refine the design.

Implement improvements for clarity and efficiency.

Finalize the design and evaluate based on usability and satisfaction.

SCENARIO: LIBRARY ROOM BOOKING SYSTEM
1. Overview
The system allows users to view available study rooms, select time slots, reserve rooms, and manage bookings. The goal is to make the process quick, transparent, and accessible for all users.

2. Target Users
User Group	Main Requirements
Students	Fast booking and clear availability info
Faculty Members	Advance scheduling and room management
Librarians	Easy monitoring and approval system
First‑Time Users	Simple navigation and clear instructions


3. User Goals
Users should be able to check room availability, select a time slot, confirm booking, receive notifications, and cancel or modify reservations easily.

4. Major Problems
Problem	Effect
Complex booking interface	Confusion and errors
Lack of real‑time updates	Double bookings
No clear confirmation	Uncertainty about reservation
Poor accessibility design	Difficult for visually impaired
Missing cancellation option	Frustration and wasted time


5. Problem Statement
Users need a simple and accessible library booking system that allows quick room reservations, real‑time updates, and easy management of bookings.

6. User Persona
Name: Meera
Age: 21
Occupation: College Student

Goal: Reserve a study room for group discussions without delays.
Needs: Real‑time availability, quick booking, and clear confirmation.
Pain Points: Confusing interface, no instant feedback, and difficulty canceling bookings.

7. User Journey
Home → View Available Rooms → Select Time Slot → Confirm Booking → Receive Notification → Cancel/Modify Booking (if needed)

8. Proposed UX Solution
The redesigned system includes a calendar‑based interface, color‑coded availability, instant confirmation pop‑ups, accessible design (large text, high contrast), and easy cancellation options. Notifications are sent via email or app alerts.

9. Usability Testing
Users perform tasks such as viewing room availability, booking a slot, and canceling a reservation. Metrics like task completion time, error rate, and satisfaction score are recorded.

10. Improvements
Based on feedback, the interface was simplified, confirmation messages were made clearer, accessibility features were enhanced, and the booking process was reduced to three steps.

UX PRINCIPLES USED
Usability: Tasks are completed efficiently with minimal errors.

Accessibility: Design supports all users, including those with visual impairments.

Consistency: Uniform layout and icons across screens.

Feedback: Clear confirmation and error messages.

Error Prevention: Validation for time slots and duplicate bookings.

Simplicity: Reduced steps and clean interface.

RESULT
Thus, the Library Room Booking System was successfully designed and evaluated. The final UX solution ensures ease of use, accessibility, efficiency, and user satisfaction, improving the overall experience of reserving study rooms.
